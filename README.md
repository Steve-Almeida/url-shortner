# URL Shortener

A URL shortening service built with Flask, PostgreSQL and Redis, fully containerized with Docker Compose.

## Architecture
Client → Flask API → Redis (cache) → PostgreSQL (persistent storage)

- Cache-aside pattern: redirects check Redis first, fall back to Postgres on a miss, then repopulate the cache.
- Short codes are generated by base62-encoding the auto-incremented database ID (no collisions).
- Per-IP rate limiting on `/shorten` using Redis counters (10 requests/minute).

## Run it
    docker compose up --build

## API
Shorten a URL:
    curl -X POST http://localhost:5000/shorten -H "Content-Type: application/json" -d '{"url": "https://example.com"}'

Use the short link: open `http://localhost:5000/<short_code>`

Health check: `GET /health`

## Tests
    cd app && pip install -r requirements.txt pytest && pytest

Tests run in GitHub Actions on every push (with a Docker image build).
